# annotation/derived

Two gold files whose round of origin is not recorded. They were kept by the annotation tooling under the paths given below; file times suggest a round, but file times are not a record, so no round is assigned. Neither file enters any result in the paper.

- `gold_dev200_rejected_folder.csv` (formerly `annotation/rejected/gold_dev200.csv`): 196 rows; columns id, gold_sentiment, gold_arc, gold_turning_point, n_raters, tp_spread. The round it was produced from is not recorded.
- `gold_dev200_UNUSABLE_alpha0.177.csv` (formerly `annotation/gold_dev200_UNUSABLE_alpha0.177.csv`): 24 rows; columns id, gold_sentiment, gold_arc, gold_turning_point, n_raters, tp_spread. The round it was produced from is not recorded.
  Its name refers to an alpha of 0.177, the round-3 sentiment value, but it has 24 rows while 26 posts were labelled by all three round-3 annotators; the discrepancy is unexplained and is stated here rather than resolved.
